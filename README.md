# LLM CostGuard · Team 8 · final presentation

A browser slide deck for the LLM CostGuard capstone. It is one self-contained `index.html` file.

**Live:** https://whybepb-rktm.github.io/costguard-deck/

## Keys

| Key | Action |
|---|---|
| → / Space | Next slide |
| ← | Previous slide |
| F | Full screen |
| N | Speaker notes |
| O | Slide overview |
| T / R | Start the timer / reset it |
| H | Help |

Add `#N` to the URL to open slide N.
